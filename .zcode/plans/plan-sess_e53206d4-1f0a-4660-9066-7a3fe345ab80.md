# 渠道/模型/分组 编辑流程重构:大弹窗 → 右侧抽屉 + 分区折叠 + 行内快改

## 现状痛点(代码层面确认)

1. 每个渠道、每个分组的**列表卡片下面各自挂一个 RelayModal**(v-for 内),渠道弹窗约 150 行 ×2 份(新建/编辑几乎重复),分组弹窗同样 ×N 份——模板爆炸、改一处要改多处。
2. 模型编辑弹窗:new/edit **两份 19 字段模板完全重复**,长上下文计费 8 个字段永远平铺,90% 的模型用不到。
3. 模型绑定/分组选模型都是**无搜索的列表海**,模型一多只能滚。
4. 模型表格不能行内改状态,启停一个模型要开完整编辑弹窗。

## 新交互设计

**统一编辑容器:右侧抽屉**(新建组件 `RelayDrawer.vue`:遮罩 + 右滑 520px 全高面板 + 标题区 + 可滚动内容 + 固定底部操作栏),替代居中大弹窗。**新建和编辑共用同一个抽屉组件**,数据 draft 由 AdminRelay 准备好传入。

### ① 渠道抽屉 `RelayChannelDrawer.vue`(替代两份渠道弹窗)

```
编辑渠道 · 主渠道                                  ✕
├─ 基本信息: 名称 | 调度策略 | 可用分组 | 启用开关 | 备注
├─ 上游供应商: 供应商卡列表(名称/规则/BaseURL/Key/优先级/权重/启用/移除) + 添加
├─ 模型绑定(已启用 12/30):
│    [搜索模型…] [类型过滤: 全部|聊天|图片…] [聊天][图片][全选][清空]
│    └ checkbox + upstream 映射输入,带搜索过滤,max-h 滚动
├─ ▸ 高级设置(默认折叠): 优先级/权重/RPM/TPM/流式并发/成本倍率
└─ 底部固定: [删除渠道]        [取消] [保存渠道]
```

### ② 模型抽屉 `RelayModelDrawer.vue`(替代两份模型弹窗)

```
├─ 基本信息: 模型ID | 显示名 | 类型 | 排序 | 启用开关
├─ 价格: 输入/输出/缓存读/缓存写/每请求价 + 一次性扣费开关
├─ ▸ 高级计费(默认折叠): 长上下文阈值/计费方式/倍数或 4 项价格
└─ 底部固定: [删除模型]        [取消] [保存模型]
```

### ③ 分组抽屉 `RelayGroupDrawer.vue`(替代 N 份分组弹窗)

```
├─ 基本信息: 代码 | 名称 | 倍率 | 启用开关
├─ 模型范围(已选 8/30): [搜索…] [类型过滤] [全选][清空] + chips 多选(带过滤)
└─ 底部固定: [删除分组]        [取消] [保存分组]
```

### ④ 列表页行内快改(少开编辑器)

- 模型表格"状态"列改为**行内启用开关**,点击即调 `updateRelayModel(id, {enabled})` 单字段保存(后端 apply 本就支持 partial),刷新本地状态;完整编辑仍走抽屉。
- 渠道卡片增加行内 **[检测]** 按钮(复用单渠道检测端点),不用去仪表盘。

## 实现要点

1. **新组件 4 个**:`admin/RelayDrawer.vue`(通用壳,teleport 到 body,ESC/遮罩关闭)、`RelayChannelDrawer.vue`、`RelayModelDrawer.vue`、`RelayGroupDrawer.vue`。draft 由 AdminRelay 传入(响应式对象引用,抽屉内直接 v-model 绑定字段),emits: `save` / `cancel` / `delete`。
2. **AdminRelay.vue 瘦身**:删除 5 处大弹窗模板(新建渠道、v-for 渠道编辑、模型 new+edit 两份、新建分组、v-for 分组编辑),替换为 3 个抽屉的挂载 + `activeChannelDraft/activeModelDraft/activeGroupDraft` 计算;`providerDraftError`、`channelPayload`、模型绑定快捷选择等逻辑全部保留原地不动。预计文件从 ~2100 行降到 ~1300 行。
3. 模型绑定/分组选模型的**搜索+类型过滤**在各自抽屉内实现(本地 query + computed 过滤),不额外抽公共组件。
4. `RelayModal` 保留给"上游模型同步"小弹窗和删除确认(AppConfirmDialog 不变)。
5. 渠道行内检测按钮复用现有 `syncRelayChannelStatusById` + toast。

## 验证

- `npm run build`(vue-tsc 类型检查 + 构建);
- 功能核对清单:渠道新建/编辑/删除、供应商增删改、模型绑定搜索与快捷选择、分组创建/编辑/删除、模型新建/编辑/删除/行内启停、同步模型弹窗不受影响;
- 后端无改动(单字段模型更新用的现有接口),`mvnw test` 回归一次确认。

## 实施顺序

① RelayDrawer 通用壳 → ② 渠道抽屉 + AdminRelay 渠道区替换 → ③ 模型抽屉 + 表格行内启停 → ④ 分组抽屉 → ⑤ 构建 + 回归验证。
