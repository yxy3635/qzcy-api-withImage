# 管理员中转报表

入口：管理员菜单「中转报表」，路径 `/admin/relay-reports`。中转站设置顶栏也提供入口。

## 功能

- 模型、分组、渠道、供应商四个维度；每行并列展示今日与历史累计的调用次数、金额、Token。
- 全站今日与历史总计，以及今日成功率、失败次数。
- 今日／累计切换，调用／金额／Token 指标切换，Top 5/8/12 排名条形图与占比环图。
- 图表点击选择明细，可查看输入、输出、缓存读取、缓存创建、其中 1 小时缓存创建 Token。
- 今日小时与最近 30 日趋势；悬停、键盘选择、点击锁定时段。
- 搜索名称或归属、隐藏无调用项目、表格排序与分页、导出当前筛选 CSV。
- 加载、空数据、查询失败状态；桌面与手机布局。

## 统计口径

数据来自 `relay_usage_log`，不包含独立生图业务。次数包含成功与失败，金额为日志 `cost` 实际扣费金额（人民币），不表示供应商成本。Token 为 `total_tokens`；输入含缓存，因此缓存细分不再重复相加。

「今日」使用后端运行时的自然日与时区；现有 Docker 环境为 `Asia/Shanghai`。页面显示实际统计日期、时区、快照时间及到期时间。累计为当前保留日志截至快照的全部记录，删除过的日志无法还原。

模型按模型代码归并，渠道和供应商按 ID 归并，同名供应商不会混合；配置改名不会拆分历史，已删除配置仍保留日志归属。当前已配置但无日志的项目显示零值。

新增 `relay_usage_log.billing_group_code`，记录派发时选中的实际计费分组；原 `group_names` 继续保存令牌允许的分组。单分组旧日志按该分组归属；多分组或空分组旧日志归入「旧记录待确认」，不把同一次调用重复分配到多个分组。旧供应商缺失记录按渠道单列为未归属／直连。

## 缓存和查询

接口：`GET /api/admin/relay/reports`，受现有 `/api/admin/**` ADMIN 权限保护，浏览器缓存禁用。

- Redis 快照 TTL 固定为 **3600 秒**，key 包含时区和日期：`imagecreater:admin:relay-report:v1:{timezone}:{date}`。
- 缓存未命中时执行一组历史聚合、今日小时聚合与近 30 日日聚合；仅传输聚合行，不拉取逐条日志；已有 `created_at` 索引支持趋势范围查询。
- 同一快照生成四个统计维度，筛选、图表、分页均在浏览器完成，无额外数据库请求。
- 进程内也保留快照至一小时；Redis 故障时继续使用本地缓存。跨日立即采用新日期快照。
- 同进程请求合并，Redis 分布式锁防止多实例同时生成。锁最长 5 分钟，按拥有者原子释放；其他实例生成中返回可重试的 503，而不启动重复历史扫描。
- 「重新加载」读取有效缓存，不绕过 TTL；到期后首次访问生成新快照。新调用和配置变化最迟在下一快照显示。
- 首次／过期后的历史聚合随日志规模增长可能较慢；不具备历史日志删改后的独立累计账本。

使用现有 Spring Redis 连接配置，无新增凭证或依赖。默认 Compose 已运行 Redis。

## 部署

更新前后端源码后，在服务器原项目目录分别执行：

```bash
docker compose build backend
docker compose up -d --no-deps --wait --wait-timeout 300 backend
docker compose build web
docker compose up -d --no-deps --wait --wait-timeout 120 web
```

后端启动时自动增加 nullable `billing_group_code` 列，数据库账号须拥有 ALTER 权限。无需重建表或重新导入全量 SQL；保留原 `.env`、Compose 项目名及数据卷。

此前生成的 `updates-20261013` 压缩包早于本次报表开发，**不包含本次报表功能**。
